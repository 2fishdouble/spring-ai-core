# 售后政策

- 签收后 7 天内，商品存在质量问题支持无理由退货；非质量问题在不影响二次销售的前提下可申请退换。
- 退货需保持商品、配件、包装完整，并在系统内提交售后申请，审核通过后 48 小时内安排上门取件。
- 退款时效：退货入库质检通过后，1-3 个工作日内原路退回支付账户。
- 运费规则：质量问题退货由平台承担运费；无理由退货运费由买家承担（含运费险则按险种理赔）。

# 发票说明

- 支持开具增值税普通发票与专用发票，订单完成后可在订单详情中申请。
- 开票抬头与税号需在下单时登记，电子发票将在申请后 24 小时内发送至预留邮箱。
- 发票内容仅支持开具订单商品明细，不支持变更抬头后重新开票。

# 隐私与联系

- 平台承诺仅在履约、售后、物流通知场景使用客户信息，不会向第三方出售个人信息。
