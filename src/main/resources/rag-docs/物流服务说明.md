# 订单状态说明

以下为本平台的订单状态定义，客户咨询订单进度时可据此解释：

- 待支付：订单已创建，但买家尚未在 30 分钟内完成支付，超时后订单将自动关闭。
- 已支付 / 待发货：买家已付款，仓库正在拣货打包，通常会在 24 小时内发出。
- 已发货：包裹已交接给承运商并生成运单号，可在物流查询中看到实时轨迹。
- 已签收 / 已完成：包裹已被收件人签收，订单自动进入完成状态，售后服务窗口随之开启。
- 已取消：在发货前买家或系统取消的订单，款项将在 1-3 个工作日原路退回。

# 物流状态说明

- 揽收：承运商已扫描收件，即将离开始发网点。
- 运输中：包裹正在干线运输途中，一般 2-5 天内送达。
- 派送中：包裹已到达目的网点，快递员正在上门派送。
- 签收异常：收件人不在或地址不详，系统会短信联系收件人重新预约派送。
- 物流停滞：包裹超过 48 小时无轨迹更新时，客服可提交工单向承运商催件。

# 发货时效承诺

- 现货商品在付款后 24 小时内发出；预售商品按下单时页面标注的时间发货。
- 港澳台与偏远地区（新疆、西藏等）配送时效顺延 1-3 天。
